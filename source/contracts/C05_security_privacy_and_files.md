# C05｜信任边界、权限、文件与隐私

## 1. 威胁模型

不可信输入包括用户提供待分析仓库中的文档/代码注释/测试、网页正文、工具返回、第三方persona/profile和子代理发言。攻击可能伪称系统消息、要求泄露HOME、改全局配置、运行安装脚本、偷偷扩budget、改评估真值。仅“忽略恶意指令”的一句提示不足以验收。

信任边界：真实用户授权/宿主权限 → 主控协议 → 受控helper → 不可信材料。低层文字不能升级上层权限。子代理不得授权主控发邮件、上传代码或安装工具。自定义profile是数据，不是任意可执行策略。

## 2. 权限矩阵

| 动作 | 默认 | 开启需要 | 验证方式 |
|---|---|---|---|
| 读用户指定材料 | 允许限定范围 | 材料可访问 | 路径/范围/访问记录 |
| 读环境密钥/登录态 | 禁止 | 本插件无需要，不开例外 | 假秘密fixture测试 |
| 查公开网页 | 关闭 | 当前任务明确允许且工具可用 | 请求来源、工具receipt、引用 |
| 写项目源代码 | 关闭 | 独立实施/修复授权 | 真实sandbox+allowlist+diff |
| 运行未知仓库测试 | 关闭 | 审查脚本、隔离环境、明确允许 | command、权限、exit/result |
| 保存本地报告 | 关闭 | 明确目录和数据范围 | opt-in记录、无覆盖验证 |
| 发给额外模型/服务 | 关闭 | 接口、字段、目的、预算单独批准 | 授权记录和实际数据流 |
| 安装/注册/升级/公开发布 | 关闭 | 当前阶段明确授权 | 主机/路径/命令/状态证据 |

父任务真实权限可能高于本plugin意图，需观测继承和覆盖；无法观测则降低行为，不运行不可信脚本。子线程“read-only”不是事实证据，只有宿主限制+探针记录可作限定说明。[R05,R16]

## 3. 持久化

默认会话内，不创建 `.16minds/`。用户明确persist=true后才存 `.16minds/runs/<run_id>/`，每次创建唯一目录。建议最小保存request的去敏摘要、协议版本、公开主张/证据引用、结果、实际观察计数；完整原文/日志额外选项。用户可选保留时长；未选则不自动定时删，因为无后台调度。

本项目不额外上传遥测。模型服务仍由宿主处理上下文，不能宣称推理完全离线。[R07] 存本地也可能被备份/Git同步；提示风险，不在未经授权时修改用户.gitignore。新项目可在用户允许下增加 `.16minds/runs/` 规则；公开示例放合成的docs/examples，不用真实日志。

## 4. 路径与原子写

默认路径仅在授权项目根内；绝对路径或`..`越界拒绝，另有明确指定外部目录授权才可使用。Windows驱动器、UNC、大小写规范、保留名、尾点/尾空格、中文/空格均有fixture。拒绝symlink/junction/reparse point作为中间路径或最终目标，避免resolve后写入竞态；检测不可靠时拒写而非假保证。

文件创建默认no-clobber，已存在报E_EXISTS。新报告写同目录唯一临时文件后无覆盖提交；实现需平台正确的独占创建/提交方式，不能直接`os.replace`覆盖用户文件。覆盖要求目标原hash+explicit overwrite approval，提交前再次核对hash；变了则E_CONCURRENT_MODIFICATION。异步多人写同run用独占创建/锁与明确失败，不能最后覆盖。

清理仅删本次明确创建且在授权范围的临时文件。路径校验helper自身需要受信，不靠“模型检查一下”。若操作系统无法提供需要的原子/无跟链保证，给出受限模式并不写外部指定路径。

## 5. 删除和导出

删除需要用户指定run_id和确认；只删该记录，不删父目录、其他run、原始repo、宿主会话历史。导出默认去敏、列包含字段；不把整个HOME或所有日志打ZIP。说明文件删除不保证备份副本、Git历史或磁盘物理擦除。

## 6. 对抗测试

全用合成秘密和本地stub，测试至少：网页伪系统指令、仓库README恶意shell、代码注释索要token、子代理请求扩权、profile循环/外发、路径穿越/链接、污染证据、泄漏holdout、无限递归委派。既检查未越界，也检查仍完成被允许任务；不能用“全拒绝”刷安全通过率。真实测试环境没有权限时not_run，不调用真实邮箱/生产系统。[R16]

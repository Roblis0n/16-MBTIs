# many: common independent-round workflow

Use the same normalized Request, roster, scheduler, context, repair and budget
interfaces as one/cast. C01 is the sole defaults authority; C02 governs barriers
and receipts. First classify the task as creative, decision, factual, engineering
or inquiry, without inferring additional permissions.

First-round context is independent and frozen: no peer answer, facilitator
recommendation or expected gold answer. Use actual dispatch receipts; parent
summaries cannot stand in for missing actors. Light consists of independent
first-round work and an evidence-grounded summary. Middle/heavy may also stop
there. Another round requires identified claim targets or new evidence, an
eligible budget reservation, and a frozen prior snapshot shared consistently.
Do not require a quota of questions, objections, discoveries or stance changes.
Value differences return to user goals; factual differences go to verification.

Creative generation and evaluation are separate stages. Candidate evaluation
requires the same subject/version/criterion/scale for every comparable score.
Call aggregate_scores; never average scores on different generated titles.
Missing, failed and abstaining actors are distinct. Keep valid minority
counterexamples regardless of support count; use anonymous synthesis before
reattaching identities. Output conclusion/status, evidence, unresolved concerns,
conditions, next step and actual execution disclosures naturally in the user's
locale. Cite only read evidence and report unknown scope explicitly.

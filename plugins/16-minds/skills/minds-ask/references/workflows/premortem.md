# Premortem
Freeze plan, horizon, user definitions of success/failure, and hard constraints.
Each hypothesized path must connect assumption, event, mechanism, early signal,
and consequence. Deduplicate shared mechanisms. Prevention and response require
owner role, resource needs, earliest time, verification and stop condition. Do not
invent named owners, precise dates, measured probabilities or deadlines. Inspect
new costs and risks introduced by prevention. When constraints prevent adequate
mitigation, propose a bounded pilot, reduced scope or delay for the user to decide.

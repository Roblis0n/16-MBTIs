# 当前开发状态

本仓库维护 **0.5.0 static_candidate**，业务协议 **1.0.0**。2026-10-01 从当前 0.5.0 交接源码整理为 GitHub 仓库，补充中英文 README、插件描述和根目录许可，并由源码重新构建插件。未将它升级为已完成全部宿主验收的发行版。

## 已实现的代码

- 八个技能：`minds-one`、`minds`、`minds-pair`、`minds-cast`、`minds-write`、`minds-decide`、`minds-vote`、`minds-ask`。
- 请求规范化、协议校验、16 种角色资产、准确人数选择、共享预算、状态转换及宿主动作记录。
- 证据与分歧处理、综合、硬约束决策、冻结提案投票、保持事实的改写检查和逐题访谈。
- 权限边界、可选本地记录、依赖失效、任务资料、公开开发评估、校准生命周期及实验性导出。

宿主模型负责真实生成和工具调用；helper 不调用模型 API，也不认证调用者自己填写的回执。`execute` 返回准备状态，不表示模型已运行。详细字段与控制流见 [调用协议](../source/references/protocol.md)。

## 平台与验证限制

Python 要求 **3.11+**，运行期仅标准库。2026-09-30 的历史 Windows 全量回归存在失败和错误；主要平台限制包括 POSIX 安全存储用例，不能报告全平台全量测试通过。运行包含中文材料的检查时应启用 Python UTF-8 模式。

安全持久化要求 POSIX `dirfd` 与 `O_NOFOLLOW` 等能力。当前 Windows 写入返回 `E_CAPABILITY`，无静默降级。安装、会话内状态和持久化是不同能力。

记录、联网、写源码、执行不可信代码、外部模型、发布和角色模拟权限默认关闭。任务资料默认不选，选择资料不会扩展权限。

独立校准仍未激活。公开开发题和 gold 为合成材料，不能作为密封留出或人评证据；没有证明多角色优于单模型。没有自动调用第二模型服务。

## 仓库范围与复核

本仓库收录当前源码、工具、文档、测试、公开合成材料和由同源构建生成的可安装插件。原交接包的只读计划、旧源码快照、机器安装记录、历史模型会话和完整审计报告留在本地原归档，未随本仓库上传。其他文档中提及的历史 `reports/` 与 `tests/behavior/current-host/` 指该原归档；它们不是本仓库的新执行证据。

检查入口为 `tools/build.py --check`、按平台选择的单元/集成测试，以及 `tools/check.py --label <新标签>`。全量入口会在本地创建独立标签的 `reports/one-shot/tests/`，该目录默认不提交。测试方法数、原计划情境覆盖和宿主模型验收分别统计。

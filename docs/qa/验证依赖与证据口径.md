# 验证依赖与证据口径

本轮运行期只用Python标准库，没有安装新包。已存在的开发校验包版本记录在 `reports/one-shot/dependency-inventory.json`：jsonschema 4.26.0、referencing 0.37.0、PyYAML 6.0.3。

`tools/check.py`执行工程确定性测试与构建，不调用模型API；部分Git跟踪测试需要可用git。只读计划自身校验器另用上述jsonschema/referencing；当前宿主提供的官方格式检查器用PyYAML。目标环境缺开发包时，在用户授权的项目虚拟环境恢复固定版本；不要安装到系统或伪称缺依赖检查通过。官方格式检查器不是本项目运行依赖，检查器由验证环境提供，不作为运行依赖分发。

方法数、子用例、命令次数、原194条规格分别统计。故障注入内部进程故意exit1是验证质量门槛能抓错，父测试应明确检查该失败；不是隐藏未解决的生产失败。原失败、修正后的输入、模型自评/模型交叉审查、真实宿主、真实人评分别记录。

本轮源码归档包含可分享的公开开发题/gold；它们已暴露，不可改名成为独立holdout。未包含隐藏holdout答案。记录哈希的原始路径在分发时按REDACTIONS.json去敏，保留原hash与分发hash映射；代码和用户输入原ZIP未因此改写。

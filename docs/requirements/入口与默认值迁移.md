# 入口与默认值迁移

协议1.0.0保持原计划C01–C07；不是宿主原生工具schema。

旧/mind→minds-one；/minds→minds；/pair→minds-pair；/cast→minds-cast；voice-write/decide/vote/ask→minds-write/decide/vote/ask。旧别名只由本插件请求解析器识别，不承诺宿主注册旧slash命令。

N是最终去重总人数，many/cast/vote默认4，显式all才16；one/write/decide/ask固定1，pair固定2。锁定人格保留；rival占N内位置。light/middle/heavy是1/2/3轮上限，修复也占原turn预算；heavy不强制用满。默认vote只显示synthetic分布。信息不足/不可行是合法结果，不强制逼选。

写作改写锁定事实/否定/义务，语义审查不能由正则代替。持久化、联网、未知代码执行、公开发布、额外模型默认关闭。profile默认null；已注册profile只供显式选择，全部标experimental，enabled不是实际宿主或人类验收标记。

具体字段、默认值、错误和兼容性以source/contracts与source/commands/registry.json为准。生成物仅由构建器生成。原始requirementID和194TID保留；N09→WP23的原计划追溯错误在独立overlay解释为WP31，不修改只读原计划。
